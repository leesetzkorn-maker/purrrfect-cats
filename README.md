# Purrrfect Cats

Premium client-preview website for Purrrfect Cats Bengal Cats, Cape Town, South Africa.

## Current build
- Premium editorial responsive homepage
- Original breeder story/details incorporated from the existing Purrrfect Cats website
- Our Bengals family section: Goya, Ice Lily, Soefia, Emma and Sterlinkie
- Kittens / next-litter architecture
- Family Match quiz demo
- Waitlist demo
- Purrrfect Journey
- Bengal education section
- Contact / enquiry CTA
- Mobile responsive layout
- GitHub Pages deployment workflow

## Safety
This repository is a preview build only. No production DNS, hosting, payment credentials, private customer data or secrets belong here.

Current photography is temporary design imagery. Replace it with approved Purrrfect Cats photography before production publication.

## Production requirements
Backend for real forms, admin dashboard, kitten records, waitlist, applications, private client portal, secure reservation/payment flow and travel tracking must be connected separately. Payfast credentials must be stored as environment secrets and never committed.
